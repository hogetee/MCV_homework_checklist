MCVNot — รุ่นทดลองสำหรับดาวน์โหลด

ต้องใช้ macOS 14 ขึ้นไป, อินเทอร์เน็ต และบัญชี CU ไม่ต้องติดตั้ง Xcode

รุ่นนี้ลงนามด้วยใบรับรอง Apple Development และยังไม่ได้ผ่านการรับรองแอปสำหรับแจกโดย Apple
จึงไม่รับรองว่าจะเปิดได้บน Mac ทุกเครื่อง ขณะนี้ตรวจบน Mac ของผู้พัฒนาเท่านั้น

1. ลาก MCVNot.app ไปที่ Applications ในหน้าต่างนี้
2. เปิด MCVNot จาก Applications หาก macOS แจ้งว่าไม่สามารถตรวจสอบผู้พัฒนาได้ และคุณเชื่อถือซอร์สของโครงการนี้ ให้คุณตัดสินใจอนุญาตเฉพาะแอปนี้เองที่ System Settings > Privacy & Security > Open Anyway
3. ในแอป กด myCourseVille แล้วเข้าสู่ระบบด้วยบัญชี CU สำหรับ IT Chula ใช้รหัสนิสิต 10 หลักเป็นชื่อบัญชี จากนั้นกด ปิดและซิงก์
4. ถ้าใช้ ClassDeeDee กด เชื่อม ClassDeeDee > Connect with Chula SSO แล้วเข้าสู่ระบบด้วยตัวเอง
5. กด เปิดแจ้งเตือน และอนุญาต จากนั้นคลิกขวาบน Desktop > Edit Widgets > การบ้าน MCV + ClassDeeDee

ห้ามเปิดแอปจากใน disk image ให้ลากไป Applications ก่อน และแทนที่แอปรุ่นเก่าแทนการเก็บหลายชุด

แนวทางเปิดแอปของ Apple: https://support.apple.com/102445
