# App icon

`AppIcon-source.png` is the approved original artwork, generated with the built-in imagegen tool. `AppIcon.icns` contains the macOS icon sizes from 16×16 through 1024×1024, converted with macOS `sips` and `iconutil` without changing the design.

## Generation prompt

Use case: logo-brand. Asset type: a single macOS application icon concept for the existing app MCVNot. Primary request: an ordinary, understated, polished app logo, independent of the app's functionality. Create one finished icon only, not a contact sheet or mockup. A centered, original geometric lowercase m emblem made of smoothly rounded, solid shapes, with a quiet neutral appearance and gentle material depth, on a simple rounded-square tile. The mark should be pleasantly balanced, highly legible at small Dock sizes, and feel like a normal everyday Mac app, with generous internal padding. Restrained colors chosen to suit that brief; no bright neon, flashy metallic effects, glass effects, or excessive gradients. Front-facing square composition. No words, app name, captions, UI, device frame, watermarks, checkmarks, calendars, bells, lists, books, or school imagery. Render as a clean high-resolution square icon with a transparent exterior around the rounded-square tile; the tile itself is opaque.
